# Statistical Business Analysis (Week 7)

## Project Overview
An end-to-end statistical analysis conducted on business sales and customer churn datasets. The analysis incorporates descriptive metrics, distribution checks, Pearson correlation, hypothesis testing (two-sample t-test, ANOVA, Chi-Square), confidence interval estimation, and multiple linear regression.
